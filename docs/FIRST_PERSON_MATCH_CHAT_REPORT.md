# 第一人称游戏聊天与战况语气

## 角色关系

本轮针对聊天“像旁观者、角色没有代入”的问题修改 SC2 场景适配层。聊天中的“我”是正在操作本局 Terran 的 Agent／小鲸鱼，“你”是人类对手；输出自己对战的反应，不替对手支招，也不以观众或解说口吻评价两个无关玩家。原始 `personas/persona-588934424a/prompt.txt` 和 `persona.json` 保留不变。

允许适度主动的游戏内挑衅与调侃，火力只落在本局操作、打法和局势；对方认真、难过或要求停止时收手。现实身份、家人、身体、地域等不作为攻击内容，不发威胁。场景适配规则只影响聊天模型，没有指挥单位、调用 QQ／网页工具或修改训练经验的权限。

## 战况语气

- 局部明显占优：得意、嘴硬、自信，可轻量挑衅。
- 局部明显承压或基地遇险：慌张、紧张、强撑嘴硬，避免落后时反向炫耀。
- 没有交战或信息不足：不确定，不因“没看到敌军”而宣称全图优势。

战况线索仅用于聊天语气，不是全局胜率或战略控制。只允许使用当前己方状态和当前可见敌情，不查询回放、隐藏敌方经济或未知军队。

估计只看靠近己军18距离或基地25距离的可见敌军，以及该交战附近18距离内的己军，使用 SDK 供给量乘当前生命比例作粗略线索；达到约1.8倍的明显差距才产生占优／承压语气。缺少对空／对地能力或生命低于40%的基地受到可见威胁时可提示紧张。附近已完成的己方静态防御参与攻击能力判断，但建筑没有可靠的供给权重，所以不强行估值，保持不确定。没有局部交战、单位数据未知或无法可靠比较时也保持不确定，不用全图己军总数与可见敌军相除。

## 使用与隔离

```powershell
.\run_human_training.cmd --human-fullscreen --chat
```

默认仍关闭，`--no-chat` 关闭。开局固定 F91《聊天流》问候、60–120 游戏秒短评、玩家聊天去重节流、独立密钥与后台线程、有限队列和超时保持原有语义。聊天记录不输入战略模型或 PPO 学习。
