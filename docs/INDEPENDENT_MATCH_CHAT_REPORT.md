# 独立游戏聊天模块

本轮新增可选游戏内聊天，用于真人 Terran 对练的开局问候、战况短评和玩家聊天回应。聊天人格为用户提供的「DeepSeek 小鲸鱼／嘴臭鲸鱼」角色卡，保存于 `personas/persona-588934424a/`。角色卡仅作为聊天模型的提示词；其中 QQ 工具名不是本程序的工具或权限，适配提示会要求只返回游戏内纯文本。

## 启动与关闭

PowerShell 中运行：

```powershell
.\run_human_training.cmd --human-fullscreen --chat
```

聊天默认关闭；关闭示例：

```powershell
.\run_human_training.cmd --human-fullscreen --no-chat
```

`--show-config` 仅显示非敏感配置，`--check-only` 只做本地检查，不开游戏、不发 API 请求。正常结束后仍由玩家输入 Y 决定是否学习，聊天开关不会代替学习批准。

## 行为与隔离

- 开局固定发送「载入《聊天流》战术，真正的比赛在比赛开始前就已经开始了。——F91.孙一峰」，无须等待 API。
- 按游戏时间随机间隔约 60–120 秒生成短评；玩家游戏内消息也可触发受限频率的回应。仅使用当前可见战况和有界聊天上下文，过滤自己的消息，避免自聊循环。
- 聊天使用独立 `CHAT_DEEPSEEK_*` 配置和 `.env.chat.local`，该文件被 Git 忽略。决策模型继续使用原 `.env.local`／`DEEPSEEK_*`，聊天没有借用决策密钥的回退逻辑。
- 聊天 HTTP 请求在独立后台线程执行，一次最多一个请求、一个结果；连接／读取超时为 3／8 秒。游戏回调不等待外部模型，也不在关闭时等待网络线程。
- 聊天初始化、API 或发送错误只记录独立诊断，聊天失败不会修改战略计划、PPO 动作或训练审批。聊天文本不注入战略提示或学习经验。
- 入站消息被视为不可信对话；聊天客户端没有游戏操作、网页、QQ 或记忆工具。输出做单行、字节长度及凭据片段过滤。保留角色卡的轻松吐槽风格与收手边界，默认不主动人身攻击。

同一台机器与游戏客户端仍共享运行资源；上述隔离避免聊天请求阻塞决策线程或改写决策状态，不将其表述为完全独立的物理进程／资源。
